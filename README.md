# 🔬 Anemia Medical Intelligence Dashboard

Aplikasi berbasis web untuk melakukan analisis mendalam terhadap dataset kesehatan anemia dan memberikan prediksi diagnosis dini menggunakan logika **Naive Bayes**.

## 🚀 Fitur Utama
* **Kalkulator Prediksi AI**: Masukkan data hemoglobin dan indeks sel darah (MCV, MCH, MCHC) untuk mendapatkan hasil diagnosis instan.
* **Dashboard Interaktif**: Visualisasi distribusi data menggunakan grafik Plotly (Histogram, Pie Chart, dan Boxplot).
* **Analisis Korelasi**: Heatmap untuk melihat hubungan antara berbagai variabel medis.
* **Manajemen Data**: Filter data berdasarkan gender atau status diagnosis dan ekspor hasil ke format CSV.

## 🛠️ Teknologi yang Digunakan
* **Python**: Bahasa pemrograman utama.
* **Streamlit**: Framework untuk antarmuka web.
* **Pandas**: Pengolahan data dataset.
* **Plotly**: Pembuatan grafik interaktif.
